# DUCKO 诺丁鸭语音交互演示

适配机器人7寸横屏的中英文讲解与语音问答原型，支持点击说话、识别文字、有限追问、回答播报、音色试听和手动导览。

- 在线体验：https://sytt198.github.io/ducko-voice-demo/
- 源码：https://github.com/sytt198/ducko-voice-demo
- 产品需求：[PRD](DUCKO语音交互PRD.html)

## 在线直接说话

1. 用正常的 Edge、Chrome 或 Firefox 打开在线网址。
2. 点击“点击说话”。首次使用会加载识别程序和模型，中文约44MB、英文约41MB，请等待“准备”完成。
3. 允许麦克风，说“介绍一下宁波诺丁汉大学”。
4. **说完点击“结束并发送”，随后显示文字并回答。** 这是整段识别，收音时不显示实时字幕。检测到停顿也会自动提交，最长15秒。
5. 再说“它在哪里”“再说一遍”“慢一点”，体验有限追问。

录音在浏览器中识别，不发送至语音云服务，不需要账号、API Key或Python。页面和模型加载完成后可继续本机处理；离线重新打开网页仍受浏览器缓存影响，不是完整PWA。

## 演示前自检

打开设置，选择“浏览器本地识别”，点击“识别示例提问”。它会真实识别一段预录的学校提问，再回答。随后再次打开设置，点击“识别示例追问”，应得到校园位置回答。自检不会打开麦克风，也不会把固定文字伪装成识别结果。

实际麦克风不出字时，在设置中查看可用麦克风并选择正确设备；录完后可回听刚才的提问，判断是否录到声音。回听音频只留在当前页面，刷新清除。

## 在本机运行

下载或克隆完整仓库，保留目录结构。

Windows安装Python 3.9或更新版本后，双击 `start_demo.cmd`，在打开的正常浏览器中演示。它会复用本机服务，默认地址为 `http://127.0.0.1:8770`。

Linux进入项目目录运行：

```bash
sh start.sh
```

打开 `http://127.0.0.1:8765`。未安装Python Vosk时，网页自动使用仓库附带的浏览器模型，不需要额外安装识别依赖。

如需使用Python本机识别：

```bash
sh setup_asr.sh zh
sh start.sh
```

详见 [Windows说明](README_WINDOWS.md)、[Python识别说明](README_ASR.md)、[浏览器识别说明](README_BROWSER_ASR.md)。不需要GPU或CUDA。

## 当前能力

- 中英文界面、三种预设声线、60段实际回答与欢迎音频。
- 九类演示答案；“介绍学校→它在哪里”使用有限上下文匹配。
- 限时连续对话：回答结束后重新收音，最长两分钟；播报时关闭麦克风。
- 三个手动导览点位；不控制机器人移动。
- 学校简介与地址附官网来源，缺少审核资料的研究方向和设备用途不编造。

这不是通用大模型问答。预置声线与节奏对比不等于情感模型控制。云端情感合成和个人音色复刻是可选功能，见 [接口说明](README_API.md)，静态网站不会直接暴露API Key。

本项目为原型演示，不表示已完成真实机器人、远场麦克风或实验室现场验收。

## 文件与开发

`index.html`为入口；`interaction.js`管理会话；`dialogue-engine.js`是问答规则；`dialogue-data.js`存答案、来源与音频；`browser-asr.js`调用浏览器Worker；`server.py`提供可选本机接口。

```bash
python -m unittest test_server.py
node test_dialogue.cjs
python build_standalone.py
```

Node仅用于开发检查。生成的单文件内嵌图像和回答音频，但浏览器识别仍需要同目录的 `vendor/`、`models-browser/` 等资源；不能把HTML单独搬走后期待麦克风识别工作。

## 第三方文件

- Vosk Browser 0.0.8及Vosk中文、英文模型使用Apache 2.0许可证，原始许可证与来源分别保留在 `vendor/vosk-browser/`、`models-browser/`。
- 音频来源与参数保留在 `audio/` 的清单中。示例自检WAV由预设语音合成生成，不是个人录音。
- 角色图像与项目内容未因公开仓库而另行授予统一的开源许可；第三方文件遵循各自许可证。
